# PhotoCallouts

전면 사진(현장 사진·조감도) 위에 번호 원과 흰 콜아웃 알약으로 위치를 짚는 장(15장), 또는 라벨 아래 캡션 한 줄만 두는 사진 장(16장).

## 부품
- `.qw-marker quote-29`: `marker`(60px) 원, `brand` 채움, `stroke-bold`(2.67) 흰 테두리, `shadow-chip-35`, 숫자 800 굵기. 장당 5개까지(15장 팀 구획 1~5).
- `.qw-callout body-24-bold`: `white-95` 알약 높이 48, `radius-pill`, `shadow-chip-30`, 글자 `ink` 24px 700 ≤10자("통합 결제 · POS").
- `.qw-caption label-26`: 사진 캡션. `--top`(16장, 라벨 아래 y 139 "5개 팀 구획  ·  통합 간판  ·  통합 결제(POS)") 또는 `--bottom`(15장 y 989 "팀별 구획  ·  점수순 시계방향 배치"). ≤30자, `shadow-text-60`. 항목 구분은 가운뎃점 ' · ' 양쪽 두 칸.

## 배치 규칙
- 라벨·번호는 SlideHeader 사진 변형(16장 라벨은 500 굵기 "CHAPTER 1 : POP-UP").
- 번호 원은 사진 속 실제 위치에, 콜아웃은 해당 물체 옆에. 겹치지 않게 최소 `gap-24` 띄운다.

## 소비자가 주는 것
사진, 라벨, 번호 원 좌표 목록, 콜아웃 [{x, y, text}], 캡션(위/아래).
