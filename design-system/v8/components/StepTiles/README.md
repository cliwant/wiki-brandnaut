# StepTiles

24장 시상 장의 단계 타일과 상금 표기.

- `.qw-step`: 왼쪽 `.qw-tile` 180×180 흰 `radius-xl` 타일 안에 니트 아이콘(높이 108) + 오른쪽 제목 `tag-30`(ink-900 "DAY 1 · 사업계획서 완성") + 설명 `body-24-light` gray-600 1줄 ≤30자. 세로로 2개(y 347, 527), 위에 구역 라벨 `tag-30` brand("사업계획서 완성 지원").
- 상금 `.qw-prize title-40-eb`(brand): 1등 "100만원"은 그대로, 2·3등은 `--sub`(불투명도 80%). 시상대 일러스트(Illustrations/podium-win.png, podium-awards-scene.jpeg) 위에 놓고 메달 아이콘(Icons/knit-medal-gold/silver/bronze)을 곁들인다.
- 합계 `title-48-eb`("총 상금 <span class=qw-hl>200만원</span>") 오른쪽 아래. 결론 2줄 `title-40`(gray-600, 강조 런 brand) 왼쪽 아래.
