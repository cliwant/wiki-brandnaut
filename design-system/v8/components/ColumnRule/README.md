# ColumnRule

5장의 3칼럼 구조: 칼럼마다 번호 달린 제목(`title-32` brand "01 이론") 아래 `rule-h`(2px) brand 선, 그 밑에 체크 항목 2~5개. 장 아래쪽에는 `.qw-key` 핵심 메시지와 사진.

## 배치 규칙
- `.qw-cols`: `col-3`(573) × 3, `gutter` 20, y=`content-y`(294). 제목과 선 사이 24, 선과 첫 항목 사이 42. 항목은 29px 들여쓴다(`.qw-col__body`).
- 칼럼 제목은 "01 ", "02 ", "03 " 두 자리 번호 + 이름(≤12자). 제목 오른쪽에 로고(airbnb·E·LAND 같은 외부 로고는 자산에 없다 — 소비자가 가져온다).
- `.qw-key`(y 798): 라벨 `body-24-medium` brand("핵심 메시지") + 문장 `title-48` 500 굵기 ink-900, 강조 런 `.qw-hl`. 2줄 ≤20자. 오른쪽 586×326 사진(Photos/crowd-crossing.png).

## 분량
칼럼당 항목 2(설명 있음) 또는 5(제목만). 제목 ≤10자, 설명 2줄 ≤24자.
