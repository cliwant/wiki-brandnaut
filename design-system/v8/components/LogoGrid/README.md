# LogoGrid

28장 협력사 로고 타일: 흰 389×114 타일을 2열로 붙여 쌓고, 열 위에 라벨 `body-24-light` 700 brand("마케팅 전문 인력", "디자인·생산 전문 인력").

- 타일 `.qw-logo-tile`: 흰 바탕, `radius-md`, 테두리 hairline `line-softer`. 로고는 타일 폭의 40~60%, 높이 ≤72. 2열 × 3~5행.
- 로고 파일은 협력사 것(CHAI, ECHO MARKETING, Moaelab, NNNAD, HUBNET, named, TMS, CFC, ECOPLANT 등)이라 자산에 넣지 않았다. 소비자가 가져오며, 없으면 덱처럼 회사명을 `body-24-light` gray-500 글자로 둔다.
- 왼쪽 열: '온라인 / 오프라인' 두 칸짜리 흰 카드(460×230, `radius-lg`)에 제휴 브랜드 로고와 설명(`body-24-light` 700 ink-900 "더크다이브 / 팝업 스토어").
