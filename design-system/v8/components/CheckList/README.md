# CheckList

체크 원 아이콘(Icons/check-circle.svg, brand) 하나에 제목·설명이 붙는 항목. 덱의 본문 목록은 거의 다 이것이다(5·14·17·21·23·26장).

## 변형
- 기본 `.qw-check`: 아이콘 `dot`(24) + 제목 `body-28-bold`(ink-900) + 설명 `body-24-light`(gray-600). 5장은 설명 첫 줄을 `<b>`(800)로 — "일단 시장에 내놓아라." 항목 간격 `gap-24`.
- `--inline`: 한 줄짜리(21장 `body-24-medium` ink, 17장 `body-16` 카드 안). 간격 `gap-16`.
- `--29`: 아이콘 29px(23장 요약 행, 26장 성과 측정 체계), 글자 `tag-30`(brand 라벨 700) / `body-24-light`(ink-900).
- 대시 목록 `.qw-dash`(11장): 24×4 `line` 대시 + 키 `body-24-medium`(ink, 133px 칸) + 값 `body-24-light`(gray-600). 값이 brand인 행(`--brand`)은 강조("번 금액과 활동 과정을 한 번에 평가").

## 분량
제목 ≤14자, 설명 2줄 ≤24자. 한 칼럼에 2~5개.
