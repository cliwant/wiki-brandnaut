# Divider

장(챕터)을 여는 전면 사진 장. 사진 위에 흰 EB 문장 하나와 섹션 라벨·페이지 번호만 둔다. 슬라이드 생성은 모든 챕터를 이 장으로 연다.

## 변형
- 기본(3장 "STORY"): `.qw-divider__statement display-128` 중앙(y 358~723), 2줄 ≤9자, `shadow-text-55`, 행간 108%.
- `--lead`(7장): 문장 `display-96` 2줄 ≤15자(y 288~595) + 아래 `.qw-divider__lead divider-lead` 2줄 ≤36자(y 629). 사진 출처는 `.qw-credit caption-15`(오른쪽 아래).
- `--bottom`(25장): 문장 `display-85` 1줄 ≤13자, 왼쪽 아래(y 888). 왼쪽 위 라벨 아래에 흰 워드마크(`.qw-divider__logo`, 331px), 오른쪽 위에 사진 인셋(`.qw-divider__inset`, 624px)을 둘 수 있다.

## 배치 규칙
- 사진은 `.qw-photo`로 전면(Photos/ 그룹, 3200×1800). 어두운 사진이어야 흰 글자가 선다(덱은 모두 야간·실내·역광 사진).
- 라벨은 사진 위에서 `on-brand`(SlideHeader 사진 변형과 같다). 헤드라인·리드는 두지 않는다.
- 챕터 이름은 라벨에("CHAPTER 2 · 8–16 WEEK"), 문장은 그 장의 주장 한 줄.

## 소비자가 주는 것
사진 파일, 라벨, 페이지 번호, 문장(1~2줄), 선택: 보충 2줄 / 출처 / 로고·인셋.
