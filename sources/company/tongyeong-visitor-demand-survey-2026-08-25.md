# 통영시 방문 수요 사전조사 — 원천 데이터 분석

## 0. 조사 개요 (제안서 기재용)

| 항목 | 내용 |
|---|---|
| 데이터 출처 | 한국관광공사 한국관광 데이터랩 — 「빅데이터 지역별 방문자수」 공공데이터 개방 API (data.go.kr, 데이터 ID 15101972) |
| 원자료 성격 | 이동통신 데이터 기반. "거주·통근·통학 등 일상생활권을 벗어나 일정시간 머문 사람"을 방문자로 정의 |
| 수집 방법 | 시군구 단위 일별 원자료를 API로 **365일 전수 수집** 후 통영시(법정동코드 48220) 추출·집계 |
| 대상 기간 | 2025-07-01 ~ 2026-06-30 (수집 시점 기준 최신 12개월 완전구간) |
| 수집 건수 | 365일 × 264개 시군구 × 3개 방문자 구분 = 289,080건 (결측·실패 0건) |
| 집계 단위 | 일자별 순방문자 수의 합계 = **연인원**. 2박 3일 방문자는 3명으로 계상됨 (출처 기관 명시 기준) |
| 방문자 구분 | 현지인(거주지 기준) / 외지인(타 지역 거주자) / 외국인 |

> 본 조사에서 **관광 수요 지표는 '외지인'을 기준**으로 한다. 현지인은 통영 거주자의 생활 이동이 포함돼 체류형 관광 수요를 대표하지 못한다.

## 4. 체류 구조 (보조 지표)

한국관광 데이터랩 분석 결과에 대한 언론 보도 기준 (2022.11~2023.10):

| 지표 | 수치 |
|---|---|
| 평균 체류시간 | **307분** (전국 기초지자체 평균 대비 +106분) |
| 숙박기간 분포 | 1박 76.0% / 2박 15.7% / 3박 이상 8.3% |
| 연간 방문자 | 16,158,511명 (전년비 +1.2%) |

*출처: 통영신문·부산일보 (한국관광 데이터랩 분석 인용). 본 항목은 API로 직접 검증되지 않은 2차 인용이므로 제안서에서는 출처를 명시해 사용한다. 참고로 같은 방식의 연간 방문자 규모(1,615만 → 1,628만)는 본 조사의 API 직접 집계와 일치하여 상호 검증된다.*

**307분 = 5시간 7분.** 통영 방문객의 평균은 반나절 체류 후 이탈이며, 숙박한 사람조차 4명 중 3명이 1박에 그친다.

## 5. 사전조사 결론 — 운영모델 설계에 주는 시사점

1. **문제는 유입량이 아니라 체류 전환율이다.** 11~12월 평일에도 3.4만 명/일이 이미 오고 있다. 신규 유치보다 **이미 온 사람을 붙잡는 설계**가 비용 대비 효율이 높다.
2. **공략 지점은 평일이다.** 주말은 이미 평일의 1.7배로 붐빈다. 오리지널스 통영이 채워야 할 빈 객실·빈 좌석은 평일에 발생한다.
3. **평일을 채우는 수요는 주말 관광객과 다른 종류다.** 주말 관광객은 일정이 고정돼 체류 연장 여지가 적다. 평일 체류를 만들 수 있는 수요는 근무 장소 제약이 없는 층(원격근무·워케이션), 일정을 스스로 정하는 팀 단위 수요(합숙·워크숍·연수), 장기체류 의향층이다. 이는 과업의 **2층 코워킹 라운지 연계상품**·**장기체류 플랫폼 입점** 요구와 정확히 일치한다.
4. **통영의 포지션은 규모가 아니라 체류 깊이다.** 여수·거제 대비 방문객 총량은 3위지만, 평균 체류시간은 전국 평균 대비 106분 길다. 총량 경쟁이 아니라 체류 시간 연장에서 이길 수 있는 도시다.
